> [!note] Conventions for new notes
> - **Filenames keep the `ChemMemo_` prefix** — wikilinks resolve by filename vault-wide, so files can move between folders without breaking links, and the prefix disambiguates in global search / graph view.
> - **Frontmatter** every note with: `type` (`hub`/`vision`/`plan`/`audit`/`spec`/`standard`), `project: ChemMemo`, `title`, `status`, `tags` (`chememo` + `chememo/<type>`), and `created`/`updated` dates.
> - **`Standards/` holds domain requirements, not build plans.** A note goes here when it describes *what a scientific record must contain* rather than *what we implement next*. It is the lab's document; the app conforms to it, not the other way round.
> - **New per-feature designs** → `Specs/` as `ChemMemo_Feature_<Name>_Spec.md`, linked from the Map of Content above.
